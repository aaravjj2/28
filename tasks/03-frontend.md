# Task 03 — Minimal Frontend

Build UI only after engine and server basics work.

## Screens

- Home
- Create/join room
- Lobby
- Game table
- Bidding panel
- Trump selection modal
- Round summary
- Match over
- Rules

## UX Requirements

- Mobile-first.
- Large tap targets.
- Legal cards highlighted.
- Illegal cards disabled.
- Current turn clearly shown.
- Partner seats clearly shown.
- Trump hidden/revealed state shown.
- Bid and declarer visible.
- Match score visible.
